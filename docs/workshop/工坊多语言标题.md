# 三款小宠物的工坊标题

对应现有六种语言，共 18 个标题。英文沿用已定下的正式名称；其他语言保留 Neuropet 和角色名，并使用当地较自然的「屏幕小宠物」表达。双宠译名明确标出 Duo 或「双宠版」。

复制表格中的标题文字到对应语言的「标题」栏即可，外侧的行内代码样式不是标题的一部分。这里不含 BBCode，也不把版本号写进标题，方便以后更新。
