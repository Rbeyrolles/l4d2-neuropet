# 动作与节奏

当前 Neuron 与 Evil 使用同一套随机行为。一次活动段落可选：左右短途散步、左右半墙探索、从左／右爬到顶部后跌落、顺／逆方向四边巡游、原地休息。休息路线的抽取权重为 2，其余各为 1。

| 项目 | 当前设置 |
| --- | --- |
| 每段速度系数 | 基准的 0.85–1.15 倍 |
| 休息时间 | 约 3–18 秒 |
| 地面移动样式 | 走路 60%，小跑 20%，慢爬 20% |
| 同程小跑速度 | 约为走路的两倍 |
| 慢爬 | 基准上限 8 HUD 单位／秒；最长随机系数下约 9.2 |
| 爬行姿势 | 两张原图按 3 fps 交替 |
| 插曲抽签 | 绊倒 20%，抱抱 20%，无插曲 60% |
| 绊倒 | 仅走路／小跑可触发，不用于慢爬、原地休息或攀爬 |
| 抱抱 | 地面移动或原地休息时可触发 |

插曲比例是每段抽签的权重，不等于每分钟发生概率。插曲在适用的一段中最多播放一次；随机未抽到时可能要等几分钟。地面移动会在插曲期间停住，随后继续。

绊倒基准全程约 3.5 秒：失衡 0.375 秒、倒地 1.5 秒、撑起 0.625 秒、坐起 0.5 秒、站稳 0.5 秒。受速度系数影响，全程约 3–4.1 秒。

抱抱基准约 3.5 秒，保留原素材双人画面。画面里的另一位角色没有独立行动逻辑，不是运行中的第二只桌宠。

## 八种休息表现

| Neuron | Evil Neuro |
| --- | --- |
| 站立眨眼 | 站立眨眼 |
| 坐下眨眼 | 坐下眨眼 |
| 趴下偷懒 | 趴下偷懒 |
| 坐着抬头 | 坐着抬头 |
| Wink | 等抱抱 |
| 比心 | 趴着害羞 |
| 站着害羞 | 站着害羞 |
| 坐着害羞 | 坐着害羞 |

部分表现是静态姿势，部分是多帧片段。Evil 原包没有 Neuron 的 Wink／比心图片，因此使用其原有替代姿势。

地面停留点会变化，墙与顶部的停留和跌落位置也有随机变化。两侧和顶部允许少量图片伸出屏幕以形成攀附感；底部没有血条避让空间，宠物可能遮挡或被原 HUD 遮挡。
