# 角色素材

`mascot_pack/Neuron` 和 `mascot_pack/Eviling` 取自本地保存的 CommentOut64/web-mascot 素材包。两包的原 PNG、动作／行为配置、元数据、署名及完整许可一并保留；这是原素材输入，生成的 VTF 不放在这里。

图片由 Paccha 绘制，素材及配置许可 CC BY-NC-SA 4.0，与根目录的 MIT 代码许可分开。原包 LICENSE 还记录了上游已经做过的配置修正。仓库保留素材文件原字节，`.gitattributes` 不对素材包做文本换行转换。

构建时进行透明边框、方向镜像、动作重排和锚点对齐；Evil 另对全透明 RGB 做轮廓颜色延伸。原 PNG 不被改写，所有转换说明和许可随 VPK 保留。

角色背景和官方渠道见 https://vedal.ai/；该链接不代表本 Mod 获得官方认可。详细权利划分见根目录 `NOTICE.md`。
